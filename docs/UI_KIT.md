# UI kit (gate G1)

Bright, icon-first pixel UI on the Tiny Swords pack + Sunnyside bars + Peaberry. Scenes only use the theme and the components below; nothing in `game/ui/` knows about `Game`, `Events` or `GameState` (a test enforces it). State is shown with icons, text carries names and numbers.

- Look at it: open `game/ui/ui_gallery.tscn` (F6). First screen = the mock HUD (`mock_hud.tscn`, copy its arrangement), scroll for every widget in every state. `-- drawer` in the user args opens the sample drawer.
- Use it: put `theme = res://game/ui/theme/fight_club_theme.tres` on the root Control of a screen (or set it as the project custom theme). Children inherit it.
- Art scale: Tiny Swords is 2:1 box-filtered (64 px icons -> 32 px), Sunnyside bars are drawn at an integer 3x, Peaberry is imported without antialiasing/subpixel so text stays crisp at 16 / 24 px. Keep sizes in multiples of these; never rescale by fractions.
- Window note: `project.godot` still has a 1280x720 base viewport with `canvas_items`/keep-aspect; the kit is laid out for a 1280x420 (min 960x420) window, so the game gate must set that base size. The capture/test scripts disable content scaling to see real pixels.

## Theme (`game/ui/theme/fight_club_theme.tres`)

Generated by `docs/ui_tools/build_theme.gd` from the derived textures in `game/ui/theme/tex/`.

| Type | Variations / notes |
| --- | --- |
| Button | normal / hover (gold rim) / pressed / disabled / focus ring; variations `RedButton` (stop, danger), `IconButton` (44 px square), `CostButton` (red disabled cost) |
| Label | `TitleLabel` 24 outlined, `NumberLabel` 24 outlined, `SmallLabel` (muted), `GoldLabel`, `DarkLabel` / `DarkSmallLabel` (on cream paper) |
| Panel, PanelContainer | cream paper. Variations `HudBar` (navy strip), `Pill` (stat pill), `Slot` (portrait well), `Chip` (trait chip), `Drawer` (slate paper), `Ribbon` (blue ribbon title), `SelectRing` |
| Panel variations | `Ring`, `SlotPanel`, `DrawerBody`, `HudPanel`, `PillPanel` (same looks for non-container use) |
| ProgressBar | gold; `MiniBar` = thin 8 px bar |
| GaugeBar styles | `HypeGauge` (orange), `ExciteGauge` (amber), `HpGauge`, `ManaGauge`: styles `base`/`fill`, constants `inset_*`, colour `mark` (read by `GaugeBar`) |
| HSlider, CheckBox, CheckButton, TabContainer, TooltipPanel, VScrollBar/HScrollBar, HSeparator/VSeparator | themed; tooltip is cream paper with dark text |
| Containers | `TightVBox`, `GaugeRow`, `ChipRow` (separation only) |

Colour language: HP green, mana blue, hype orange (flame), excitement amber, money gold. Tiers never rely on colour alone (icon + name + divider marks).

## Icons (`resources/ui/icons/`, 32x32)

Drawn: `star`, `star_half`, `star_empty`, `flame` (hype), `crowd` (seats), `trophy`, `lock`, `play`, `pause`, `laurel` (fame), `fireworks`, `megaphone` (announcer), `spotlight`, `drink` (bar), `poster`, `scroll` (stories), `calm` / `burst` (excitement tiers). From Tiny Swords Icon_xx (halved): `coin`, `sword`, `shield`, `hammer`, `gear`, `info`, `close`, `meat`. Hero portraits: `resources/ui/avatars/avatar_01..25.png` (64 px). Regenerate with `docs/ui_tools/make_icons.gd` and `build_ui_textures.gd` (then `--import`).

## Components (`game/ui/components/*.tscn`)

All are dumb: `@export` properties, setters and signals only. Set properties before or after `add_child`. Sizes are minimums.

| Component | Purpose | API | Min size |
| --- | --- | --- | --- |
| `IconButton` (Button) | icon-only action / toggle | `icon_texture`, `tip` (tooltip), `toggle_mode`, `set_active(bool)` (no signal); signals `pressed`, `toggled` | 44x44 |
| `CostButton` (Button) | `[coin] cost` buy button | `cost`, `label`, `currency_icon`, `unaffordable`, `set_gold(gold)` (disables when cost > gold); signal `pressed` | 84x40 |
| `StatPill` (PanelContainer) | icon + short number/text (gold, seats, fame) | `icon`, `value`, `set_value(v, animate=true)` (counts + pops), `text` (overrides number), `prefix`, `suffix`, `progress` 0..1 (-1 hides), `set_progress()` | 56x37 |
| `HypeGauge` (HBox) | hype 0-100 with flame, manager threshold notch | `value`/`set_value`, `threshold`/`set_threshold` (-1 hides), `is_ready_to_book()`; at >= threshold the bar pulses and the flame bounces | 200x32 |
| `ExcitementGauge` (HBox) | excitement 0-100 with tier dividers | `value`/`set_value`, `tier_marks` (25, 60), `tier_names`, `tier_icons` (default calm/star/burst), `multiplier_text`/`set_multiplier`, read-only `tier` | 260x52 |
| `GaugeBar` (Control, used by both gauges) | themed bar with marks + marker | `style`, `value`, `max_value`, `marks`, `marker`, `hot`, `animate`, `inner_rect()`, `x_at(v)` | 96x26 |
| `HeroCard` (MarginContainer) | portrait, name, level, HP/mana, trait chips | `portrait`, `hero_name`, `level`, `hp`/`mana` (0..1) or `set_hp(cur,max)`/`set_mana`, `set_traits(icons, tips)`, `selected`, `disabled`; signal `pressed` | 184x80 |
| `PixelBar` (Control) | Sunnyside HP/mana bar at 3x, any ratio | `kind` (HP/MANA/RED), `ratio`, `pixel_scale` | 45x21 |
| `TraitChip` | one trait icon chip (used by HeroCard) | `set_icon(tex, tip)` | 30x26 |
| `StarRating` (HBox) | 1-5 stars, halves, certain vs possible | `set_value(v)`, `set_range(lo, hi)`, `min_value`, `max_value`; stars past `lo` up to `hi` are translucent | 160x32 |
| `Badge` (Control) | round marker with count / text / icon | `count`/`set_count`, `text`, `icon`, `tint`, `pulsing`, `show_empty`; hides itself when empty | 24x24 |
| `Toast` (PanelContainer) | icon + text that slides up, holds, fades, frees | `setup(icon, text, life=2.2)` before `add_child` into a plain (non-container) layer; signal `finished` | text size |
| `Drawer` (PanelContainer) | slide-in panel, ribbon title, close button | `title`, `edge` (RIGHT/LEFT/BOTTOM), `panel_size`, `margin`, `open()`, `close()`, `is_open`, `get_body()`; ESC (`ui_cancel`) or the X closes; signals `opened`, `closed` | 240x160 |

Placement rules: a Drawer lives in a full-rect Control (it slides against the parent's size); a Toast lives in a plain Control anchored where toasts should appear; hero traits and portraits are plain `Texture2D`s (a 64x64 avatar is cropped 1:1, other sizes shown as is).

## Tests and captures

- `godot --headless --path . --script res://game/tests/run_all.gd` (runner now waits one frame so the scene tree is ready) runs `test_ui_kit.gd`: theme entries, icon set, every component scene + setters, gallery layout at 960x420 / 1280x420 / 1600x560 (all controls inside the window, only the scroll area may run past the bottom, no overlapping HUD groups or bar children), no `Game`/`Events`/`GameState` in `game/ui/*.gd`.
- Screenshots need a real window (not headless): `godot --path . --resolution 1280x420 --script res://.godot/capture_gallery.gd -- w=1280 h=420 [scroll=600] [drawer] [tag=name] [crop=x,y,w,h zoom=4]` writes `.godot/captures/<tag>_<w>x<h>.png`. ## HUD (gate G2)

The real screens live next to the kit in `game/ui/` and are the only UI scripts allowed to name `Game` / `Events` (`test_ui_kit.gd` allow-lists `hud.gd`, `main_menu.gd`, `pause_menu.gd`). They reach both through two overridable vars, `game` and `events`, which default to `/root/Game` and `/root/Events` in `_ready`; tests assign their own (`core_kit.gd`) **before** `add_child`. Everything is composed from the components above; state flows `Game command -> Events signal -> widget setter`, no polling.

| Scene | What it is |
| --- | --- |
| `hud.tscn` (`Hud`, full-rect, mouse ignore) | `Layout` VBox = `TopBar` (52 px) / `Middle` (fills; holds `%Excitement`, `%Drawers`, `%Toasts`) / `BottomBar` (96 px). Only bars, buttons and open drawers take the mouse, so the town stays draggable. |
| `pause_menu.tscn` | Modal overlay (`%Resume`, `%SaveMenu`, `%Quit`). `open()` pauses through `Game.set_paused(true)`, `close()` resumes. Signals `main_menu_requested`, `quit_requested`. Child of the HUD, forwarded by it. |
| `main_menu.tscn` | Title, `%NewGame`, `%Continue` (disabled + tooltip without a valid save, via `SaveStore.load_state`), `%Quit`, overwrite confirmation (`%Confirm`). Signals `new_game_requested`, `continue_requested`, `quit_requested`; `refresh()` re-checks the save. The shell does the `Game.new_game()` / `continue_game()`. |
| `router.gd` (`DrawerRouter`) | `register(key, scene_path)`, `open(key)`, `close()`, `current`, `has_drawer(key)`, `signal drawer_changed(key)`. One drawer at a time, lazy instancing into `host`; the `context` dict is set as properties on each drawer (`game`, `events`); ESC or right click closes. Never pauses. |
| `drawers/manager_drawer.tscn` | Drawer with manager on/off, "Book at hype >= X" slider (30-95; a mouse drag commits on release because every `set_manager` autosaves) and a live "Books in ~N s" line (inverse of `Hype.grow`). |

HUD wiring: gold / fame / hype / crowd pills and the hype threshold marker follow `gold_changed`, `fame_changed`, `hype_changed`, `manager_changed`; hero cards (preferred lineup, `HeroPortraits`) rebuild on `roster_changed`, and during a fight HP / mana follow `combat_event` (hits, healing, `CombatSim.MANA_*`); the excitement gauge exists only between `fight_started` and `fight_finished`. Book calls `Game.book_fight(Game.state.preferred_lineup)` and is disabled, with a tooltip reason, while a fight runs, the game is paused or the lineup is invalid. Roster opens `drawers/roster_drawer.tscn` when that file exists (else disabled); Build and Stories are locked placeholders. Toasts: `Events.toast` plus a summary after every fight.

Shell API: `hud.main_menu_requested`, `hud.quit_requested`, `hud.open_pause()`, `hud.router`, `hud.toggle_drawer(key)`, `hud.sync_all()`, `hud.show_toast(icon_name, text)`. ESC with no drawer open opens the pause menu. Drawers receive `game` / `events` from the router context, so a new drawer script only declares `var game: Node` / `var events: Node` and falls back to the autoloads.

Tests: `test_hud_widgets.gd`, `test_hud_drawers.gd`, `test_hud_menus.gd`, `test_hud_layout.gd`. Screenshots (real window): `.godot/hud_demo.gd` -> `.godot/captures/hud_*.png`. A new `class_name` (`DrawerRouter`) needs one `godot --headless --path . --import` before scripts using it load from a cold class cache.
