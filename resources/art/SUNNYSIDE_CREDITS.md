# Sunnyside World art

Sunnyside World by Daniel Diggle (DANIEL DIGGLE Ltd), used from the asset pack supplied with this project.

Original pack and usage terms: https://danieldiggle.itch.io/sunnyside

Original files remain under `asset/Sunnyside_World_Assets`. The game assembles the supplied terrain, buildings, character bodies, hair and animation layers at runtime. Small class weapons, building signs and training props are native Godot drawings created for this project. Character identities, animation choices and building assemblies are game-specific adaptations.
